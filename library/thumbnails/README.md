# Thumbnails and cover images (`public/thumbnails/`)

One subfolder per topic: `public/thumbnails/<topic-slug>/<variant>.png`.

Rendered by the `thumbnail-generator` agent. Do not edit generated PNGs by hand, regenerate with a new variant suffix (`-v2`, `-v3`) instead.

Canonical dimensions:

| Platform | Aspect | Pixels |
|---|---|---|
| YouTube | 16:9 | 1280x720 |
| IG feed square | 1:1 | 1080x1080 |
| IG feed portrait | 4:5 | 1080x1350 |
| IG story / Reels cover | 9:16 | 1080x1920 |
| LinkedIn post | ~2:1 | 1200x627 |
| LinkedIn banner | ~4:1 | 1584x396 |
| Profile picture | 1:1 | 800x800 |
