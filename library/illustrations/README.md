# Illustrations (`public/illustrations/`)

SVG or PNG illustrations for use in videos and social posts.

## Sources (in order of preference)

1. **unDraw** — https://undraw.co . MIT-style license, commercial OK, no attribution required. Single-accent recolor before download. Best default for tech/educational content.
2. **Humaaans** by Pablo Stanley — https://www.humaaans.com . CC-BY, attribution required. Track any use in `CREDITS.md`.
3. **Storyset** by Freepik — https://storyset.com . Free tier requires attribution. Avoid unless attribution is acceptable.

## Icons vs illustrations

- **Icons** (24-32px, single-purpose glyphs): use `lucide-react` in code, do NOT store as files here.
- **Illustrations** (larger, scene-setting art): store as SVG here.

## Naming

`<subject>-<variant>.svg`, kebab-case. Examples: `developer-thinking.svg`, `queue-abstract-1.svg`, `server-rack-teal.svg`.

## Attribution tracking

If any file is not CC0 / MIT / permissive-no-attribution, add to `CREDITS.md`:

```
- developer-thinking.svg — Humaaans by Pablo Stanley (CC-BY 4.0), https://www.humaaans.com
```
