In the last topic you learned what a database is. Now your Python program will actually use one. It will create a table, add two students, and print them back.

Before a program can touch any data, it must open a connection to the database. Think of it like a phone call: you dial first, then you talk, then you hang up.

## Connecting Python to a Database

A connection lets your program work with stored data. You need one before any data operation. Python has libraries that make connecting easy. Once connected, the program can add, retrieve and change data. Handling the connection properly keeps the talk between Python and the database smooth.

## Using sqlite3 or MySQL to Establish a Database Connection

The book names two choices:

| | sqlite3 | MySQL |
|---|---|---|
| Comes with Python? | Yes, built in | No |
| Where data lives | one single file on your computer | a separate database system |
| Used for | small databases | larger and more complex systems |

:::definition{source="Computer Science 12 (PECTAA), topic 4.2b"}
The sqlite3 library is built into Python and is used for small databases.
:::

To connect, you give the database details, such as its name. MySQL also needs credentials, like a username and password. Once the connection works, Python can access the database. This chapter uses sqlite3, because there is nothing to install.

### Example

This is the book's full program. It creates a file called `school.db`.

```python
# Import sqlite3 module
import sqlite3
# Connect to the database file named "school.db"
# If the file does not exist, SQLite will create it automatically
connection = sqlite3.connect("school.db")
# Create a cursor object
# Cursor is used to execute SQL queries
cursor = connection.cursor()
# Create "students" table if it does not exist
cursor.execute(""" CREATE TABLE IF NOT EXISTS students
 ( id INTEGER PRIMARY KEY, name TEXT, age INTEGER, grade TEXT ) """)
# (Optional) Insert sample data
cursor.execute("INSERT INTO students (name, age, grade) VALUES ('Ali', 14, '8th')")
cursor.execute("INSERT INTO students (name, age, grade) VALUES ('Sara', 15, '9th')")
# Save changes
connection.commit()
# This query selects all columns (*) from the table named "students"
cursor.execute("SELECT * FROM students")
# Fetch all records returned by the query
# fetchall() returns a list of rows/records
records = cursor.fetchall()
# Display all records
# Loop through each row in the records list
for row in records:
    # Print each row of the table
    print(row)
# Close the database connection
connection.close()
```

Step by step:

- `import sqlite3` loads Python's built-in SQLite library.
- `sqlite3.connect("school.db")` opens the file `school.db`. If the file is not there, SQLite creates it.
- `connection.cursor()` makes a cursor. A cursor is the object that carries your SQL commands to the database.
- The `CREATE TABLE IF NOT EXISTS` command makes a `students` table with four columns: `id`, `name`, `age` and `grade`. `id` is the primary key. The words `IF NOT EXISTS` mean the table is only created the first time.
- The two `INSERT` commands add Ali and Sara. Notice that they do not give an `id`. The database fills it in.
- `connection.commit()` saves the new rows to the file.
- `SELECT * FROM students` asks for every column of every row. The `*` means "all columns".
- `fetchall()` collects the results as a list. Each item in the list is one row.
- The `for` loop prints each row, one per line.
- `connection.close()` ends the connection.

On the first run you should see:

```text
(1, 'Ali', 14, '8th')
(2, 'Sara', 15, '9th')
```

The book sums up the program in five steps:

- **Connect to Database:** Establishes a connection to the school.db SQLite database.
- **Create Cursor:** Creates a cursor object to execute SQL commands.
- **Execute Query:** Executes a SQL query to fetch all records from the students table.
- **Fetch and Display Data:** Fetches all records and prints each row in the result.
- **Close Connection:** Closes the database connection after the operation.

:::warning
Forgot `commit()`? Then your INSERT is lost when the program ends. Every INSERT, UPDATE or DELETE needs a `commit()` to be saved.
:::

:::tip
Run the program again and Ali and Sara are added a second time, so you will see four rows. Also, `school.db` is created in the folder you run the program from. Run it from a different folder and you get a new, empty file.
:::

## Executing SQL Commands From Python

Python talks to the database by sending SQL commands. It sends them through the cursor, with `cursor.execute()`. Some commands create tables. Some insert data. A `SELECT` command reads data back. With these commands, a Python program can fully manage its data.

:::did-you-know
Professional programmers never build SQL by joining strings with user input. They use `?` placeholders instead, like `cursor.execute("INSERT INTO students (name, age, grade) VALUES (?, ?, ?)", (name, age, grade))`. This blocks a common attack called SQL injection.
:::
