Almost every program you use has windows, buttons and boxes you can click. That is a graphical user interface, or GUI. In this chapter you learn to build GUIs yourself in Python.

This first part explains what a GUI is. Then it walks you through your first Tkinter program.

## Graphical User Interface (GUI) Development with Tkinter

A program can talk to its user in two ways. In a command-line interface, the user types text commands. In a GUI, the user sees windows, buttons, labels and text boxes. The user simply clicks or types into them.

The book says GUIs are more user-friendly than command lines. They are also easier to use. Python gives you tools to build GUI programs quickly. The main tool in this chapter is Tkinter, Python's built-in library for GUI programs. It is simple and widely used.

:::did-you-know
Before GUIs, people typed every command, for example `copy file1.txt file2.txt`. The Xerox Star (1981) and the Apple Macintosh (1984) changed that. They made computers point-and-click.
:::

## What is a GUI? Why is it important?

:::definition{source="Computer Science 12 (PECTAA), topic 4.1a"}
A GUI, or Graphical User Interface, is a visual interface that allows users to interact with software using elements like buttons, menus, and forms.
:::

Why does a GUI matter? It shows you what you can do. You do not need to remember long commands. You also get visual feedback: you click, and something on the screen changes. So people who are not technical can still use the program easily.

The book lists three places where GUIs are common: desktop software, web applications and mobile apps.

:::example
Desktop: Microsoft Word, VS Code and File Explorer. Web: YouTube, Gmail and Google Docs. Mobile: WhatsApp, Instagram and Zoom. You used a GUI every time you opened one of these.
:::

## Overview of Tkinter as Python's built-in GUI toolkit

:::definition{source="Computer Science 12 (PECTAA), topic 4.1a"}
Tkinter is Python's standard GUI toolkit that comes pre-installed with the language.
:::

"Pre-installed" means you do not download anything extra. Tkinter gives you ready-made classes and functions. With them you create windows, buttons, labels, entry fields and other widgets. A widget is any single element on the screen, like a button or a text box.

Tkinter is easy to learn and lightweight. It suits small to medium-sized programs. It also supports event-driven programming. This means the program waits, and an action runs only when the user does something, such as clicking a button.

### Example

Here is the book's first Tkinter program. Type it exactly as shown.

```python
import tkinter as tk

# Create main window
window = tk.Tk()
window.title("Simple GUI Example")
window.geometry("300x200")

# Function to handle button click (event)
def on_click():
    label.config(text="Button Clicked!")

# Create a label
label = tk.Label(window, text="Welcome to Tkinter")
label.pack(pady=10)

# Create an entry field
entry = tk.Entry(window)
entry.pack(pady=10)

# Create a button
button = tk.Button(window, text="Click Me", command=on_click)
button.pack(pady=10)

# Run the application
window.mainloop()
```

What each part does:

- `import tkinter as tk` loads Tkinter and gives it the short name `tk`.
- `window = tk.Tk()` creates the main window. `title()` sets the text in its title bar.
- `geometry("300x200")` makes the window 300 pixels wide and 200 pixels tall.
- `def on_click():` defines a function. It uses `config()` to change the label's text to "Button Clicked!".
- `tk.Label(...)` makes a label that shows "Welcome to Tkinter".
- `pack(pady=10)` places a widget in the window, with 10 pixels of space above and below it.
- `tk.Entry(window)` makes an empty box where the user can type.
- `tk.Button(..., command=on_click)` makes a button. `command` links it to the `on_click` function, so every click runs that function.
- `window.mainloop()` starts the program. It keeps the window open and waits for the user.

When you run it, a window titled "Simple GUI Example" appears. You see the welcome label, an empty entry box and a "Click Me" button. Click the button, and the label changes to "Button Clicked!".

The book sums up the program like this:

| Code | Job (book wording) |
|---|---|
| `Tk()` | creates main window |
| `Label` | displays text |
| `Entry` | takes user input |
| `Button` | performs action |
| `command=on_click` | event handling (button click) |
| `mainloop()` | runs the GUI |

:::did-you-know
Python's own code editor, IDLE, is built with Tkinter. So is Thonny, a Python editor used in many schools. Under the hood, Tkinter uses a toolkit called Tcl/Tk. That is why the same Tkinter program runs on Windows, Mac and Linux.
:::
