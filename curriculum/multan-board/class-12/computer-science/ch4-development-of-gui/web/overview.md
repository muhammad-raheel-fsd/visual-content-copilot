In this chapter you build real desktop programs with windows, buttons and text boxes, using Tkinter, the GUI library that comes with Python. You learn to arrange widgets with pack(), grid() and place(), and to make buttons run your own functions, ending with a simple login form. The second half connects Python to a database with SQLite, so your programs can create, read, update and delete stored records.
