# Chapter 4 Summary (verbatim from book, page 57)

The book's Summary section at the end of Chapter 4 is a 12-term glossary. Each term is reproduced here character-for-character so students revise from the exact wording they will see on the paper.

## Graphical User Interface

A Graphical User Interface (GUI) is a visual way of interacting with a computer program using windows, buttons, menus, text boxes, and other graphical elements.

## Tkinter

Tkinter is Python's built-in library used to create desktop-based graphical user interfaces.

## Window

A window is the main screen or container in a GUI application where different interface elements are displayed.

## Frame

A frame is a container used to organize and group widgets inside a GUI window.

## Widget

A widget is a GUI element, such as a label, button, entry field, menu, or listbox, used to display information or receive input from the user.

## Event-Driven Programming

Event-driven programming is a programming approach in which the program responds to events or actions performed by the user.

## Relational Database

A relational database stores data in tables consisting of rows and columns, where related data can be connected using keys.

## SQL

Structured Query Language (SQL) is a language used to create, manage, and manipulate data in relational databases.

## Create Operation

The Create operation is used to add new records to a database.

## Read Operation

The Read operation is used to retrieve and display data from a database.

## Update Operation

The Update operation is used to modify existing records in a database.

## Delete Operation

The Delete operation is used to remove records from a database safely.
