## 4.2 Working with Databases in Python

Working with databases in Python involves storing and managing data using database systems. Python programs can connect to databases to insert, retrieve, update, and delete data. Databases allow applications to handle large amounts of information efficiently. Using databases helps maintain data accuracy and consistency. Python supports database operations through built-in and external libraries.

### DO YOU KNOW? (blue callout)

Databases allow programs to store large amounts of information safely and retrieve it quickly when needed.

## Introduction to Databases

A database is an organized collection of data stored in a structured format. It allows data to be accessed and managed easily. Databases reduce data duplication and improve reliability. They support secure storage of information. Databases are commonly used in many types of software applications.

### Entity

**Entity:** An entity is a real-world object, person, place, event, or concept about which data is stored in a database.

**Example:** Student, Teacher, Course, Book, Employee

### Attribute

**Attribute:** An attribute is a property or characteristic of an entity. It describes specific information about an entity.

**Example:** For the entity Student, attributes can be:
- Student Name
- Roll Number
- Class
- Age

### Relationship

**Relationship:** A relationship shows how two or more entities are connected with each other.

**Example:** A Student enrols in a Course. Here, enrols in is the relationship between Student and Course.

### Identifier

**Identifier:** An identifier is an attribute that uniquely identifies each record or object of an entity.

**Example:** For the entity Student, Roll Number can be used as an identifier because each student has a unique roll number.

## Understanding Databases

Databases store important data required for application operation. They allow applications to manage large data sets effectively. Key database concepts are:

- **Relational Database:** A database that stores data in tables (rows and columns) and links them using relationships.
- **Table:** A collection of related data organised in rows (records) and columns (fields). (as shown in Figure 4.3).
- **Column:** A property or characteristic of an entity (e.g., name, age).
- **Primary Key:** A unique identifier for each record in a table.
- **Foreign Key:** A field that links one table to another by referring to the primary key of another table.

## Overview of Relational Databases and SQL Structure

Relational databases organize data into tables made of rows and columns. Each table stores related data in a structured manner. Relationships between tables are maintained using keys. SQL stands for Structured Query Language and is used to interact with databases. SQL commands help create, read, update, and delete data.
