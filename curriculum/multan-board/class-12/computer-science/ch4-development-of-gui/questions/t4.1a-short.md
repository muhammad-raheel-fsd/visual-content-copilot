## Q1

**Question:** Define a Graphical User Interface (GUI).

**Answer:** A GUI, or Graphical User Interface, is a visual interface that allows users to interact with software using elements like buttons, menus, and forms. GUI applications are widely used in desktop software, web applications, and mobile apps.

**Marks:** 2

**Difficulty:** easy

---

## Q2

**Question:** Why is a GUI important in application development?

**Answer:** GUIs are important because they make programs easier to understand and operate, especially for non-technical users. They improve usability by providing visual feedback and reducing the need to remember complex commands.

**Marks:** 3

**Difficulty:** medium

## Q3

**Question:** What is Tkinter?

**Answer:** Tkinter is Python's standard GUI toolkit that comes pre-installed with the language. It provides a set of classes and functions to create windows, buttons, labels, entry fields, and other widgets. It is easy to learn, lightweight, and supports event-driven programming.

**Marks:** 3

**Difficulty:** easy

## Q4

**Question:** List four Tkinter widgets used in the book's "Simple GUI Example" and their purpose.

**Answer:**
1. Tk() creates the main window.
2. Label displays text.
3. Entry takes user input.
4. Button performs an action.

## Q5

**Question:** What does `mainloop()` do in a Tkinter application?

**Answer:** mainloop() runs the GUI. It keeps the application window open and waits for user events (like button clicks) until the window is closed.

**Marks:** 2

**Difficulty:** medium

---

## Q6

**Question:** Explain what `command=on_click` does in a Tkinter Button.

**Answer:** command=on_click is event handling for a button click. It tells Tkinter which function to run when the user clicks the button. In the book's example, clicking the "Click Me" button calls the on_click function, which updates the label to show "Button Clicked!".

**Marks:** 3

**Difficulty:** medium
