## Q1

**Question:** Explain what widgets and frames are in Tkinter. Walk through the book's "Tkinter Frames Example" code and its 5-bullet explanation.

**Answer_hint:**
Cover three parts:

1. **Widgets (verbatim):**
   "Tkinter provides many components, called widgets, that help build interactive graphical applications. A program can contain multiple visual elements such as windows, frames, buttons, and text fields. These widgets allow users to enter data, choose options, or perform actions. Each widget has its own purpose, and combining them creates a complete interface. Tkinter also supports layout management, so widgets can be arranged neatly on the screen."

2. **Frames and main window (verbatim):**
   "A Tkinter program begins by creating a main window, which serves as the base for all other elements. The window can be resized, given a title, and designed to hold different widgets. Frames are sections within the window that help organize content. Frames divide the window into smaller parts, making it easier to group related widgets. This structure improves clarity and keeps the interface well-arranged."

3. **Code walkthrough + 5-bullet explanation (verbatim):**
   Full code from the book:
   ```python
   import tkinter as tk

   window = tk.Tk()
   window.title("Tkinter Frames Example")
   window.geometry("400x300")

   top_frame = tk.Frame(window, bg="lightblue", height=100)
   top_frame.pack(fill="x")

   bottom_frame = tk.Frame(window, bg="lightgreen", height=200)
   bottom_frame.pack(fill="both", expand=True)

   label_top = tk.Label(top_frame, text="Top Frame", bg="lightblue")
   label_top.pack(pady=20)

   label_bottom = tk.Label(bottom_frame, text="Bottom Frame", bg="lightgreen")
   label_bottom.pack(pady=50)

   window.mainloop()
   ```

   Verbatim 5-bullet explanation:
   - Tk() creates main window
   - Frame divides window into sections
   - top_frame and bottom_frame organize layout
   - pack() places frames and widgets
   - Frames help keep the GUI clean and well-structured

   Expected output: a 400 x 300 window with a light-blue top band labelled "Top Frame" and a light-green bottom section labelled "Bottom Frame".

## Q2

**Question:** Describe the five common Tkinter widgets mentioned in the book (Label, Button, Entry, Menu, Listbox) and give one short code example for each.

**Answer_hint:**
List all 5 widget definitions verbatim then show a code snippet for each.

1. **Label** (verbatim): "A Label is used to display text or messages on the screen."
   ```python
   label = tk.Label(window, text="Welcome")
   label.pack()
   ```

2. **Button** (verbatim): "A Button allows the user to perform an action when it is clicked."
   ```python
   button = tk.Button(window, text="Click Me", command=on_click)
   button.pack()
   ```

3. **Entry field** (verbatim): "An Entry field is used to enter text, such as a name or password."
   ```python
   entry = tk.Entry(window)
   entry.pack()
   ```

4. **Menu** (verbatim): "A Menu provides a list of options at the top of the window."
   ```python
   menu = tk.Menu(window)
   menu.add_command(label="File")
   window.config(menu=menu)
   ```

5. **Listbox** (verbatim): "A Listbox shows a list of items and allows selection from the list."
   ```python
   listbox = tk.Listbox(window)
   for item in ["Red", "Green", "Blue"]:
       listbox.insert("end", item)
   listbox.pack()
   ```
