## Q8

**Question:** In the login form code, what does `tk.Entry(window, show="*")` do?

**Options:**
- a) Deletes the password
- b) Shows the password as plain text
- c) Masks each typed character with a `*` so the password is hidden on screen
- d) Prints a star to the console

**Correct:** c

**Explanation:** The `show="*"` parameter tells the Entry widget to display each character as `*` instead of the real character. This is why passwords look like `****` on screen.
