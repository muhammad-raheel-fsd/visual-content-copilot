## Q1

**Question:** Describe all four CRUD operations. For each, give the verbatim book definition and the SQL command from Table 4.1.

**Answer_hint:**
Cover all four with verbatim definitions + Table 4.1 commands:

1. **Create: Adding New Records (verbatim):**
   "The Create operation is used to add new data to a database table. It stores information such as names, values, or records. SQL insert commands are used for this purpose. Python sends these commands to the database. New records become part of the stored data after execution."
   SQL: `INSERT INTO students (ID, Name, Age) VALUES (1, 'John', 20);`
   Description: Adds a new record to a table.

2. **Read: Retrieving and Displaying Data (verbatim):**
   "The Read operation is used to fetch data from the database. It helps display stored records when needed. SQL select commands are commonly used for reading data. Python retrieves the results and processes them. This operation does not change the stored data."
   SQL: `SELECT * FROM students;`
   Description: Retrieves data from a table.

3. **Update: Modifying Existing Records (verbatim):**
   "The Update operation changes existing data in a database. It is used when stored information needs correction. SQL update commands modify selected records. Python executes these commands based on conditions. Only the specified data is changed during this process."
   SQL: `UPDATE students SET Age = 21 WHERE ID = 1;`
   Description: Modifies an existing record in a table.

4. **Delete: Removing Data Safely (verbatim):**
   "The Delete operation removes unwanted data from a database. It helps keep the database clean and accurate. SQL delete commands are used with conditions. Python ensures only selected records are removed. Careful use prevents loss of important data."
   SQL: `DELETE FROM students WHERE ID = 1;`
   Description: Removes a record from a table.

Close with: Every database-based application depends on CRUD. Python uses SQL commands and `cursor.execute()` + `commit()` to perform these operations.

## Q2

**Question:** Walk through the Delete example from the book line by line. Include the full Python code and explain each statement.

**Answer_hint:**
Full verbatim code:

```python
import sqlite3

# Connect to the database
connection = sqlite3.connect("school.db")

# Create a cursor object
cursor = connection.cursor()

# Execute DELETE query (example: delete student with ID = 1)
cursor.execute("DELETE FROM students WHERE ID = 1")

# Save changes
connection.commit()

# Display confirmation
print("Record deleted successfully")

# Close the connection
connection.close()
```

Line-by-line:
- `import sqlite3`: load the built-in sqlite3 module.
- `connection = sqlite3.connect("school.db")`: open school.db. If missing, SQLite creates it.
- `cursor = connection.cursor()`: get a cursor to run SQL through.
- `cursor.execute("DELETE FROM students WHERE ID = 1")`: run the DELETE statement that removes the row where ID equals 1. The WHERE clause makes sure only one record is deleted.
- `connection.commit()`: save the change to disk. Without this, the delete would not be permanent.
- `print("Record deleted successfully")`: confirmation message for the user.
- `connection.close()`: close the connection, releasing the file lock.

End with the book's 3-bullet summary verbatim:
- `DELETE FROM students WHERE ID = 1` · removes a specific record
- `connection.commit()` · saves the changes in database
- Without `commit()`, deletion will not be permanent

## Q3

**Question:** Write a Python program that performs all four CRUD operations on a `students` table (ID, Name, Age) using sqlite3. Explain each operation briefly.

**Answer_hint:**
Expected full code (follows the book's connection + commit + close pattern):

```python
import sqlite3

# Connect to the database (creates school.db if missing)
connection = sqlite3.connect("school.db")
cursor = connection.cursor()

# Create the students table if it does not exist
cursor.execute(""" CREATE TABLE IF NOT EXISTS students
 ( ID INTEGER PRIMARY KEY, Name TEXT, Age INTEGER ) """)

# ---- CREATE (INSERT) ----
cursor.execute("INSERT INTO students (ID, Name, Age) VALUES (1, 'John', 20)")
cursor.execute("INSERT INTO students (ID, Name, Age) VALUES (2, 'Sara', 18)")
connection.commit()

# ---- READ (SELECT) ----
cursor.execute("SELECT * FROM students")
records = cursor.fetchall()
print("After CREATE:")
for row in records:
    print(row)

# ---- UPDATE ----
cursor.execute("UPDATE students SET Age = 21 WHERE ID = 1")
connection.commit()

cursor.execute("SELECT * FROM students WHERE ID = 1")
print("After UPDATE:", cursor.fetchall())

# ---- DELETE ----
cursor.execute("DELETE FROM students WHERE ID = 2")
connection.commit()

cursor.execute("SELECT * FROM students")
print("After DELETE:")
for row in cursor.fetchall():
    print(row)

# Close the connection
connection.close()
```

Brief explanation of each step:
- **Create:** Two INSERT statements add John and Sara. commit() saves them.
- **Read:** SELECT * returns both rows. fetchall() gives a list of tuples; the for loop prints each.
- **Update:** UPDATE changes John's age from 20 to 21. commit() saves. A second SELECT confirms the change.
- **Delete:** DELETE removes Sara (ID 2). commit() saves. A final SELECT shows only John remaining.

Note: every write operation (CREATE, UPDATE, DELETE) needs a commit() to be permanent. Read (SELECT) does not need commit() because it does not change the stored data.
