## Q1

**Question:** Define an event in a GUI program.

**Answer:** An event is an action, such as clicking a button or typing text. The program waits for an event instead of running all the time. When an event occurs, a specific task is performed.

**Marks:** 2

**Difficulty:** easy

---

## Q2

**Question:** What is event-driven programming?

**Answer:** Event-driven programming is based on actions called events. The program remains idle until an event occurs. Common events include button clicks and key presses. Each event is linked to a specific function. The function runs only when the event happens. This approach saves system resources.

**Marks:** 3

**Difficulty:** easy

## Q3

**Question:** How does Tkinter connect a widget to a function?

**Answer:** Widgets are connected to functions in the program through the `command=` parameter. For example, `tk.Button(window, text="Login", command=check_login)` links the button click to the `check_login` function. When the widget is used, the connected function executes.

**Marks:** 3

**Difficulty:** medium

## Q4

**Question:** What does `entry.get()` do?

**Answer:** The `.get()` method on an Entry widget returns the text currently typed inside the field. In the book's login form, `username = entry_user.get()` reads whatever the user typed in the Username field.

**Marks:** 2

**Difficulty:** easy

## Q5

**Question:** What is `messagebox` used for in Tkinter?

**Answer:** `messagebox` is imported from `tkinter` and is used to show small popup windows for success or error messages. `messagebox.showinfo(title, message)` opens an information popup and `messagebox.showerror(title, message)` opens an error popup. The book uses both to tell the user if login succeeded or failed.

**Marks:** 3

**Difficulty:** medium

## Q6

**Question:** Walk through what happens when the user clicks the Login button in the book's login form.

**Answer:**
1. The user clicks the Login button, which fires a click event.
2. Tkinter sees the event and calls the function linked by `command=check_login`.
3. `check_login()` reads the Entry fields with `entry_user.get()` and `entry_pass.get()`.
4. It compares them to `"admin"` and `"1234"`.
5. If they match, `messagebox.showinfo("Success", "Login Successful!")` opens a success popup. Otherwise, `messagebox.showerror("Error", "Invalid Username or Password")` opens an error popup.

**Marks:** 4

**Difficulty:** medium

## Q7

**Question:** What does `show="*"` do when passed to `tk.Entry()`?

**Answer:** `show="*"` tells the Entry widget to display each typed character as `*` instead of the real character. This hides the password on screen while still letting the program read the real text with `.get()`. The book uses it for the password field: `entry_pass = tk.Entry(window, show="*")`.

**Marks:** 2

**Difficulty:** easy
