## Q1

**Question:** Walk through the complete sqlite3 example from the book: connect, create table, insert data, select data, print, and close. Explain each step.

**Answer_hint:**
Reproduce the full code and explain line by line:

```python
import sqlite3

connection = sqlite3.connect("school.db")
cursor = connection.cursor()

cursor.execute(""" CREATE TABLE IF NOT EXISTS students
 ( id INTEGER PRIMARY KEY, name TEXT, age INTEGER, grade TEXT ) """)

cursor.execute("INSERT INTO students (name, age, grade) VALUES ('Ali', 14, '8th')")
cursor.execute("INSERT INTO students (name, age, grade) VALUES ('Sara', 15, '9th')")
connection.commit()

cursor.execute("SELECT * FROM students")
records = cursor.fetchall()
for row in records:
    print(row)

connection.close()
```

Step-by-step (using the book's 5-bullet summary):

1. **Connect to Database:** `sqlite3.connect("school.db")` establishes a connection to the school.db SQLite database. If the file does not exist, SQLite creates it automatically.
2. **Create Cursor:** `connection.cursor()` creates a cursor object. The cursor is used to execute SQL commands.
3. **Create table + insert data:** `cursor.execute()` runs SQL commands. `CREATE TABLE IF NOT EXISTS students(...)` creates the students table if it is not already there. The two INSERT statements add two rows (Ali and Sara). `connection.commit()` saves these changes to the file.
4. **Execute Query + Fetch and Display Data:** `cursor.execute("SELECT * FROM students")` runs a SELECT query to fetch all records. `cursor.fetchall()` returns a list of rows. The `for row in records: print(row)` loop prints each row.
5. **Close Connection:** `connection.close()` closes the database connection after the operation. Closing frees the file lock so other programs can access the file.

Expected output after running:
```
(1, 'Ali', 14, '8th')
(2, 'Sara', 15, '9th')
```

## Q2

**Question:** Describe the 5-step pattern for executing SQL commands from Python. Illustrate each step with an example from the book's code.

**Answer_hint:**
The 5-step pattern (verbatim bullets from the book):

1. **Connect to Database.** Establishes a connection to the SQLite database.
   Example: `connection = sqlite3.connect("school.db")`
   This opens (or creates) the school.db file. The returned connection object represents the open database.

2. **Create Cursor.** Creates a cursor object to execute SQL commands.
   Example: `cursor = connection.cursor()`
   The cursor is the thing you talk to when you want the database to run a query. Every SQL statement goes through it.

3. **Execute Query.** Executes a SQL query to interact with the data.
   Example: `cursor.execute("CREATE TABLE IF NOT EXISTS students (id INTEGER PRIMARY KEY, name TEXT, age INTEGER, grade TEXT)")` and `cursor.execute("INSERT INTO students (name, age, grade) VALUES ('Ali', 14, '8th')")` and `cursor.execute("SELECT * FROM students")`.
   Also: write operations need `connection.commit()` to actually save to the file.

4. **Fetch and Display Data.** Fetches all records returned by a SELECT query and prints each row.
   Example: `records = cursor.fetchall()` returns a list of rows. `for row in records: print(row)` prints each one.

5. **Close Connection.** Closes the database connection after the operation.
   Example: `connection.close()`
   This releases the file lock and frees the connection resource.

Close with: this 5-step pattern (connect → cursor → execute → fetch → close) works for every relational database Python supports, not just sqlite3. The only change is the import and the connect call (`pymysql.connect(host=..., user=..., password=..., database=...)` for MySQL).
