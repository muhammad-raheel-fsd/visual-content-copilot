## Q1

**Question:** Describe event-driven programming in Tkinter and walk through the book's Simple Login Form code line by line.

**Answer_hint:**
Cover three parts:

1. **Event-driven programming (verbatim):**
   "Event-driven programming is based on actions called events. The program remains idle until an event occurs. Common events include button clicks and key presses. Each event is linked to a specific function. The function runs only when the event happens. This approach saves system resources."

   Add: Tkinter runs `window.mainloop()` which is an infinite loop that waits for events. When one arrives (click, keypress), Tkinter looks up the linked function and calls it, then returns to waiting.

2. **Login form walkthrough (verbatim code sections):**
   ```python
   import tkinter as tk
   from tkinter import messagebox
   ```
   Import Tkinter and the messagebox submodule for popup dialogs.

   ```python
   window = tk.Tk()
   window.title("Login Form")
   window.geometry("300x200")
   ```
   Create the main window, give it a title, set size to 300 by 200 pixels.

   ```python
   def check_login():
       username = entry_user.get()
       password = entry_pass.get()
       if username == "admin" and password == "1234":
           messagebox.showinfo("Success", "Login Successful!")
       else:
           messagebox.showerror("Error", "Invalid Username or Password")
   ```
   Define the function that will run when the Login button is clicked. It reads the Entry fields, compares them to the hard-coded `"admin"` and `"1234"`, and shows an info or error popup.

   ```python
   tk.Label(window, text="Username").pack()
   entry_user = tk.Entry(window)
   entry_user.pack()
   ```
   Create a Username label and entry field. Save the entry in `entry_user` so `check_login()` can call `.get()` on it later.

   ```python
   tk.Label(window, text="Password").pack()
   entry_pass = tk.Entry(window, show="*")
   entry_pass.pack()
   ```
   Create the Password label and entry. `show="*"` masks the typed characters on screen.

   ```python
   tk.Button(window, text="Login", command=check_login).pack(pady=10)
   window.mainloop()
   ```
   Create the Login button. The key line is `command=check_login`, which links the click event to the function. `window.mainloop()` starts the event loop that waits for events.

3. **Verbatim 5-bullet summary:**
   - Entry  ·  takes username and password
   - Button  ·  submits data
   - check_login()  ·  checks input
   - messagebox  ·  shows success or error
   - Works on event-driven programming

## Q2

**Question:** Write a Tkinter calculator app with two Entry fields and a button that adds the two numbers and shows the result in a messagebox. Explain how event handling connects the button to the add function.

**Answer_hint:**
Expected code (following the book's event-handling pattern):

```python
import tkinter as tk
from tkinter import messagebox

# Create main window
window = tk.Tk()
window.title("Add Two Numbers")
window.geometry("300x200")

# Function to add numbers
def add_numbers():
    a = entry_a.get()
    b = entry_b.get()
    try:
        result = float(a) + float(b)
        messagebox.showinfo("Result", f"{a} + {b} = {result}")
    except ValueError:
        messagebox.showerror("Error", "Please enter valid numbers")

# First number label and entry
tk.Label(window, text="First number").pack()
entry_a = tk.Entry(window)
entry_a.pack()

# Second number label and entry
tk.Label(window, text="Second number").pack()
entry_b = tk.Entry(window)
entry_b.pack()

# Add button
tk.Button(window, text="Add", command=add_numbers).pack(pady=10)

# Run application
window.mainloop()
```

Explain event handling:
- `tk.Entry(window)` creates the input fields; `.get()` reads what the user typed.
- `tk.Button(window, text="Add", command=add_numbers)` connects the button click (an event) to the `add_numbers` function. This is the same `command=` pattern the book uses in its Login Form.
- When the user clicks Add, Tkinter sees the click event, looks up the function linked via `command=`, and calls `add_numbers()`.
- `add_numbers()` reads both entries, converts them to numbers with `float()`, adds them, and shows the result in `messagebox.showinfo(...)`. If the user typed something that is not a number, `float()` raises `ValueError` and `messagebox.showerror(...)` shows an error popup.
- `window.mainloop()` runs the event loop that keeps waiting for events until the user closes the window.

This follows the same event-driven pattern as the book's login form: idle until an event, event triggers a function, function updates the UI through a messagebox.
