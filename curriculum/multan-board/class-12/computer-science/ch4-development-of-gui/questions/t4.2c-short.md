## Q1

**Question:** Define CRUD.

**Answer:** CRUD stands for Create, Read, Update, and Delete and defines basic database actions. These operations are used to manage data stored in a database. Every database-based application depends on CRUD operations.

**Marks:** 2

**Difficulty:** easy

---

## Q2

**Question:** Explain the Create operation with its SQL command.

**Answer:** The Create operation is used to add new data to a database table. SQL insert commands are used for this purpose. Example from Table 4.1: `INSERT INTO students (ID, Name, Age) VALUES (1, 'John', 20);` adds a new record to the students table.

**Marks:** 3

**Difficulty:** easy

---

## Q3

**Question:** Explain the Read operation with its SQL command.

**Answer:** The Read operation is used to fetch data from the database. It helps display stored records when needed. This operation does not change the stored data. Example from Table 4.1: `SELECT * FROM students;` retrieves all records from the students table.

**Marks:** 3

**Difficulty:** easy

---

## Q4

**Question:** Explain the Update operation with its SQL command.

**Answer:** The Update operation changes existing data in a database. It is used when stored information needs correction. Only the specified data is changed during this process. Example from Table 4.1: `UPDATE students SET Age = 21 WHERE ID = 1;` modifies the student with ID 1 to have Age 21.

**Marks:** 3

**Difficulty:** medium

---

## Q5

**Question:** Explain the Delete operation with its SQL command.

**Answer:** The Delete operation removes unwanted data from a database. It helps keep the database clean and accurate. SQL delete commands are used with conditions. Example from Table 4.1: `DELETE FROM students WHERE ID = 1;` removes the student record with ID 1.

**Marks:** 3

**Difficulty:** medium

---

## Q6

**Question:** What does `commit()` do in CRUD operations, and what happens if you forget it?

**Answer:** `connection.commit()` saves the changes in the database. It is required after any Create (INSERT), Update, or Delete operation. Without commit(), the write operation stays in memory and is not permanent · for example, "Without commit(), deletion will not be permanent" (from the book's Delete example).

**Marks:** 3

**Difficulty:** medium

---

## Q7

**Question:** Why does the book title the Delete section "Delete: Removing Data Safely"?

**Answer:** Delete permanently removes rows from the database. If used carelessly (for example, DELETE without a WHERE clause), it can wipe the entire table. The book says: "SQL delete commands are used with conditions. Python ensures only selected records are removed. Careful use prevents loss of important data." The word "Safely" highlights that developers must always include a WHERE condition to target only the intended rows.

**Marks:** 3

**Difficulty:** medium
