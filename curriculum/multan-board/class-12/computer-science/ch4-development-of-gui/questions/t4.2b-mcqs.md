## Q7

**Question:** What does `CREATE TABLE IF NOT EXISTS students (...)` do?

**Options:**
- a) Deletes the students table
- b) Creates the students table only if it does not already exist
- c) Renames the students table
- d) Always creates a new copy of the table

**Correct:** b

**Explanation:** `IF NOT EXISTS` tells SQLite to skip the create statement if the table is already there, so running the program multiple times does not raise an error.

**Difficulty:** medium

**Bloom:** apply

- b) Saves the changes to the database file
- c) Creates a new cursor
