# Chapter 4 · Mock Test (Punjab Board style)

**Time Allowed:** 60 minutes · **Total Marks:** 40

---

## Section A · Multiple Choice Questions (10 × 1 = 10 marks)

Choose the correct option. Each MCQ carries 1 mark.

### A1

In Tkinter, the function `window.mainloop()` is used to:

- a) Create a new window
- b) Close the window
- c) Start the event loop that keeps the window running
- d) Install Tkinter

**Correct:** c

---

### A2

The Tkinter method that arranges widgets in rows and columns is:

- a) pack()
- b) grid()
- c) place()
- d) column()

**Correct:** b

---

### A3

In the login form example, `tk.Entry(window, show="*")` is used to:

- a) Delete the entry field
- b) Mask typed characters with `*` so the password is hidden on screen
- c) Print `*` to the terminal
- d) Center the entry field

**Correct:** b

---

### A4

Which SQL command retrieves data from a table?

- a) INSERT
- b) UPDATE
- c) SELECT
- d) DELETE

**Correct:** c

---

### A5

A Primary Key is:

- a) A password for the database
- b) A unique identifier for each record in a table
- c) The first column of any table
- d) The name of a database engine

**Correct:** b

---

### A6

Without calling `connection.commit()` after an INSERT, what happens?

- a) The database file is deleted
- b) The INSERT is not permanently saved
- c) The program crashes
- d) A warning email is sent

**Correct:** b

---

### A7

In Figure 4.3 (Student + Department tables), DeptID in the Student table is a:

- a) Primary Key
- b) Foreign Key
- c) Composite Key
- d) Candidate Key

**Correct:** b

---

### A8

Which of the following is NOT a Tkinter widget mentioned in the book?

- a) Label
- b) Button
- c) Entry
- d) DatePicker

**Correct:** d

---

### A9

The method that positions widgets using x,y coordinates is:

- a) pack()
- b) grid()
- c) place()
- d) align()

**Correct:** c

---

### A10

CRUD stands for:

- a) Create, Read, Update, Delete
- b) Copy, Retrieve, Update, Download
- c) Create, Run, Upload, Delete
- d) Create, Remove, Update, Manage

**Correct:** a
