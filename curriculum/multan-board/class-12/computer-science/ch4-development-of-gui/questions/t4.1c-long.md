## Q1

**Question:** Explain layout management in Tkinter. Describe the three layout methods pack(), grid(), and place() with a code example of each.

**Answer_hint:**
Cover four parts:

1. **Layout management (verbatim):**
   "Layout management is used to arrange widgets inside a window in a proper way. It decides the position and size of each widget on the screen. Good layout management makes the interface clear and easy to use. It also helps in keeping the window organized. Tkinter provides different methods to manage layout."

2. **pack() (verbatim definition + code):**
   "The pack() method places widgets in a simple vertical or horizontal order. It is easy to use and works well for small applications."
   ```python
   button1 = tk.Button(window, text="Button 1", width=12)
   button1.pack(pady=10)
   button2.pack(pady=10)
   button3.pack(pady=10)
   ```

3. **grid() (verbatim definition + code):**
   "The grid() method arranges widgets in rows and columns like a table. It is useful for forms and structured layouts."
   ```python
   button1.grid(row=0, column=0, padx=10, pady=20)
   button2.grid(row=0, column=1, padx=10, pady=20)
   button3.grid(row=1, column=0, columnspan=2, padx=10, pady=10)
   ```

4. **place() (verbatim definition + code):**
   "The place() method positions widgets at exact locations on the window. It gives more control but needs careful adjustment."
   ```python
   button1.place(x=30, y=40)
   button2.place(x=170, y=85)
   button3.place(x=30, y=140)
   ```

End with the "Designing Clean and Responsive Interfaces" guidance: well-arranged widgets, enough space between them, text and buttons clear and easy to read, interface adjusts when window size changes.

## Q2

**Question:** Write a Tkinter program that uses grid() to design a simple login form with two Labels (Username, Password), two Entry fields, and one Login Button spanning both columns. Explain each grid() call.

**Answer_hint:**
Expected code (following the book's grid() example pattern):

```python
import tkinter as tk

# Create main window
window = tk.Tk()
window.title("Login Form")
window.geometry("300x200")

# Create widgets
label_user = tk.Label(window, text="Username")
label_pass = tk.Label(window, text="Password")
entry_user = tk.Entry(window)
entry_pass = tk.Entry(window, show="*")
login_button = tk.Button(window, text="Login", width=20)

# Arrange using grid()
label_user.grid(row=0, column=0, padx=10, pady=10)
entry_user.grid(row=0, column=1, padx=10, pady=10)

label_pass.grid(row=1, column=0, padx=10, pady=10)
entry_pass.grid(row=1, column=1, padx=10, pady=10)

# Login button spans two columns
login_button.grid(row=2, column=0, columnspan=2, padx=10, pady=20)

# Keep content centred
window.grid_columnconfigure(0, weight=1)
window.grid_columnconfigure(1, weight=1)

# Run the application
window.mainloop()
```

Line-by-line explanation using the book's grid() pattern:
- `label_user.grid(row=0, column=0, ...)` places the Username label in row 0, column 0.
- `entry_user.grid(row=0, column=1, ...)` places the Username entry next to the label.
- `label_pass.grid(row=1, column=0, ...)` places the Password label in row 1.
- `entry_pass.grid(row=1, column=1, ...)` places the Password entry next to it. The `show="*"` hides characters.
- `login_button.grid(row=2, column=0, columnspan=2, ...)` places the Login button in row 2, spanning both columns (same `columnspan=2` pattern as the book's Button 3 example).
- `window.grid_columnconfigure(0, weight=1)` and `window.grid_columnconfigure(1, weight=1)` keep the content centred by giving both columns equal weight (verbatim from the book's grid() example).

This produces a classic login form layout: 2 rows of label-plus-entry at the top, a full-width Login button below.
