## Q1

**Question:** How do you connect Python to a SQLite database?

**Answer:** Import the sqlite3 module and call `sqlite3.connect("school.db")`. The sqlite3 library is built into Python. The connect() call opens the database file. If the file does not exist, SQLite creates it automatically.

**Marks:** 3

**Difficulty:** easy

---

## Q2

**Question:** What is a cursor and what is it used for?

**Answer:** A cursor is an object created from a database connection with `connection.cursor()`. It is used to execute SQL queries against the database. Every SQL command (CREATE TABLE, INSERT, SELECT, UPDATE, DELETE) is run by calling `cursor.execute(sql_string)`.

**Marks:** 3

**Difficulty:** easy

---

## Q3

**Question:** What does `commit()` do and why is it important?

**Answer:** `connection.commit()` saves the changes made by INSERT, UPDATE, or DELETE statements to the database file. Without calling commit(), the changes stay in memory and are lost when the program ends. The book's example calls commit() after the two INSERT statements.

**Marks:** 3

**Difficulty:** medium

---

## Q4

**Question:** Differentiate between sqlite3 and MySQL.

**Answer:** sqlite3 is built into Python and is used for small databases. It stores all the data in a single file on the system, which is simple and portable. MySQL is used for larger and more complex database systems, typically running on a server with multiple users connecting over the network.

**Marks:** 3

**Difficulty:** medium

---

## Q5

**Question:** What does `cursor.fetchall()` return?

**Answer:** `fetchall()` returns a list of rows (records) produced by the last SELECT query. Each row is typically a tuple of column values. The book loops through the list with `for row in records: print(row)` to display every record.

**Marks:** 2

**Difficulty:** easy

---

## Q6

**Question:** Why do we close the database connection at the end of the program?

**Answer:** `connection.close()` releases the database connection and the file lock. On SQLite, closing lets other programs open the same file. On MySQL, closing frees the connection on the server so it can serve other clients. The book calls close() as the very last step of the example.

**Marks:** 2

**Difficulty:** easy
