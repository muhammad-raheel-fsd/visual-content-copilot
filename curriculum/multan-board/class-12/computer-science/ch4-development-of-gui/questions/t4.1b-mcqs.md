## Q5

**Question:** In the Frames Example code, `top_frame.pack(fill="x")` means:

**Options:**
- a) The frame will be invisible
- b) The frame will fill the window horizontally
- c) The frame will be deleted
- d) The frame will scroll

**Correct:** b

**Explanation:** `fill="x"` tells pack() to make the frame expand to fill the window along the x-axis (horizontally). The book shows `top_frame.pack(fill="x")` for the top light-blue frame.

**Difficulty:** medium

**Bloom:** apply

## Q6

**Question:** In the Frames Example code, `bottom_frame.pack(fill="both", expand=True)` means:

**Options:**
- a) The frame fills the remaining space in both directions
- b) The frame is hidden
- c) The frame contains only buttons
- d) The frame disappears when the window is resized

**Correct:** a

**Explanation:** `fill="both"` fills both horizontally and vertically; `expand=True` lets the frame take up any extra available space. The book uses this for the bottom light-green frame.

**Difficulty:** hard

**Bloom:** apply
