## Q1

**Question:** Define a database.

**Answer:** A database is an organized collection of data stored in a structured format. It allows data to be accessed and managed easily. Databases reduce data duplication and improve reliability. They support secure storage of information.

**Marks:** 3

**Difficulty:** easy

---

## Q2

**Question:** Define an entity and give three examples.

**Answer:** An entity is a real-world object, person, place, event, or concept about which data is stored in a database. Examples from the book: Student, Teacher, Course, Book, Employee.

**Marks:** 2

**Difficulty:** easy

---

## Q3

**Question:** What is an attribute? Give the attributes of the Student entity as listed in the book.

**Answer:** An attribute is a property or characteristic of an entity. It describes specific information about an entity. For the entity Student, the book lists these attributes: Student Name, Roll Number, Class, Age.

**Marks:** 3

**Difficulty:** easy

---

## Q4

**Question:** What is a relationship in a database? Give one example.

**Answer:** A relationship shows how two or more entities are connected with each other. Example from the book: A Student enrols in a Course. Here, "enrols in" is the relationship between Student and Course.

**Marks:** 2

**Difficulty:** easy

---

## Q5

**Question:** What is an identifier? Why is Roll Number a good identifier for Student?

**Answer:** An identifier is an attribute that uniquely identifies each record or object of an entity. Roll Number is a good identifier for Student because each student has a unique roll number, so no two students can have the same value.

**Marks:** 3

**Difficulty:** medium

---

## Q6

**Question:** Differentiate between Primary Key and Foreign Key.

**Answer:** A Primary Key is a unique identifier for each record in a table (no two records can have the same value). A Foreign Key is a field that links one table to another by referring to the primary key of another table. Example from Figure 4.3: RollNo is the primary key of Student; DeptID in Student is a foreign key that refers to DeptID (primary key) in the Department table.

**Marks:** 3

**Difficulty:** medium

---

## Q7

**Question:** Define a relational database and a table.

**Answer:** A relational database is a database that stores data in tables (rows and columns) and links them using relationships. A table is a collection of related data organised in rows (records) and columns (fields).

**Marks:** 3

**Difficulty:** easy

---

## Q8

**Question:** What is SQL and what are the four kinds of actions it helps perform?

**Answer:** SQL stands for Structured Query Language and is used to interact with databases. SQL commands help create, read, update, and delete data. These four actions together are known as CRUD operations.

**Marks:** 2

**Difficulty:** easy
