## Q9

**Question:** In the book's grid() example, what does `button3.grid(row=1, column=0, columnspan=2, padx=10, pady=10)` do?

**Options:**
- a) Hides Button 3
- b) Places Button 3 in row 1 starting at column 0 and spanning two columns
- c) Deletes Button 3
- d) Puts Button 3 at pixel 10,10

**Correct:** b

**Explanation:** `row=1` is the second row, `column=0` is the leftmost column, `columnspan=2` makes it stretch across both columns. The book code places Button 3 across the full width below Button 1 and Button 2.

**Difficulty:** hard

**Bloom:** apply

## Q10

**Question:** In the grid() example, what does `window.grid_columnconfigure(0, weight=1)` and `window.grid_columnconfigure(1, weight=1)` together do?

**Options:**
- a) They delete columns 0 and 1
- b) They give both columns equal weight so the content stays centred
- c) They freeze the window
- d) They disable grid layout

**Correct:** b

**Explanation:** From the book comment: "# Keep content centred". Setting equal `weight=1` on both columns tells Tkinter to split extra space equally between them, keeping the content centred when the window is resized.

**Difficulty:** hard

**Bloom:** analyze
