## Q1

**Question:** Explain the concept of a Graphical User Interface (GUI). Describe Tkinter as Python's built-in GUI toolkit and walk through the book's "Simple GUI Example" code with its 6-bullet explanation.

**Answer_hint:**
Cover three parts verbatim:

1. **GUI concept (verbatim):**
   "A GUI, or Graphical User Interface, is a visual interface that allows users to interact with software using elements like buttons, menus, and forms. GUIs are important because they make programs easier to understand and operate, especially for non-technical users. They improve usability by providing visual feedback and reducing the need to remember complex commands. GUI applications are widely used in desktop software, web applications, and mobile apps."

2. **Tkinter overview (verbatim):**
   "Tkinter is Python's standard GUI toolkit that comes pre-installed with the language. It provides a set of classes and functions to create windows, buttons, labels, entry fields, and other widgets. Tkinter is easy to learn, lightweight, and supports event-driven programming, where actions are triggered by user events. It is suitable for building small to medium-sized GUI applications quickly and efficiently."

3. **The Simple GUI Example code walkthrough (verbatim 6 bullets):**
   - Tk() → creates main window
   - Label → displays text
   - Entry → takes user input
   - Button → performs action
   - command=on_click → event handling (button click)
   - mainloop() → runs the GUI

   Describe how each line of the example code (`import tkinter as tk`, `window = tk.Tk()`, `window.title("Simple GUI Example")`, `window.geometry("300x200")`, `def on_click():`, `label = tk.Label(window, text="Welcome to Tkinter")`, `label.pack(pady=10)`, `entry = tk.Entry(window)`, `entry.pack(pady=10)`, `button = tk.Button(window, text="Click Me", command=on_click)`, `button.pack(pady=10)`, `window.mainloop()`) maps to one of the 6 building blocks and what the output window looks like.

## Q2

**Question:** Write a complete Tkinter program (based on the book's style) that creates a window titled "Welcome App" of size 300x200, shows the label "Hello, Student!", has an entry field, and a button labelled "Greet" that, when clicked, changes the label to "Greetings from Tkinter!". Explain each line of your code.

**Answer_hint:**
The student is expected to adapt the book's Simple GUI Example code. Full working program:

```python
import tkinter as tk

# Create main window
window = tk.Tk()
window.title("Welcome App")
window.geometry("300x200")

# Function to handle button click (event)
def on_click():
    label.config(text="Greetings from Tkinter!")

# Create a label
label = tk.Label(window, text="Hello, Student!")
label.pack(pady=10)

# Create an entry field
entry = tk.Entry(window)
entry.pack(pady=10)

# Create a button
button = tk.Button(window, text="Greet", command=on_click)
button.pack(pady=10)

# Run the application
window.mainloop()
```

Line-by-line explanation using the book's 6 building blocks:
- `import tkinter as tk` imports the built-in Tkinter library and gives it the short name tk.
- `window = tk.Tk()` creates the main window (Tk() → creates main window).
- `window.title("Welcome App")` sets the window's title bar text.
- `window.geometry("300x200")` sets the window size to 300 pixels wide and 200 pixels tall.
- `def on_click():` defines the function that runs when the button is clicked. It uses `label.config(text=...)` to change the label's displayed text.
- `label = tk.Label(window, text="Hello, Student!")` creates the Label (Label → displays text).
- `label.pack(pady=10)` places the label in the window with 10 pixels of vertical padding.
- `entry = tk.Entry(window)` creates the Entry field (Entry → takes user input).
- `entry.pack(pady=10)` places the entry below the label.
- `button = tk.Button(window, text="Greet", command=on_click)` creates the Button (Button → performs action) and `command=on_click` is event handling (button click): when clicked, on_click runs.
- `button.pack(pady=10)` places the button below the entry.
- `window.mainloop()` runs the GUI (mainloop() → runs the GUI) and keeps the window open until the user closes it.
