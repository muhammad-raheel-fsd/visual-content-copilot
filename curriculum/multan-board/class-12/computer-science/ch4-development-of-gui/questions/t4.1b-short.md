## Q1

**Question:** What are widgets in Tkinter?

**Answer:** Tkinter provides many components, called widgets, that help build interactive graphical applications. A program can contain multiple visual elements such as windows, frames, buttons, and text fields. These widgets allow users to enter data, choose options, or perform actions.

**Marks:** 3

**Difficulty:** easy

---

## Q2

**Question:** What is a Frame in Tkinter and why is it used?

**Answer:** Frames are sections within the window that help organize content. Frames divide the window into smaller parts, making it easier to group related widgets. This structure improves clarity and keeps the interface well-arranged.

**Marks:** 3

**Difficulty:** medium

---

## Q3

**Question:** How do you create a main window and add frames in Tkinter?

**Answer:** A Tkinter program begins with `window = tk.Tk()` to create the main window. The window can be resized, given a title, and designed to hold different widgets. Frames are added using `tk.Frame(window, bg="color", height=N)` and placed with `.pack()`.

**Marks:** 3

**Difficulty:** medium

## Q4

**Question:** List any three Tkinter widgets with their purpose.

**Answer:**
1. **Label**: displays text or messages on the screen.
2. **Button**: allows the user to perform an action when it is clicked.
3. **Entry field**: used to enter text, such as a name or password.

**Marks:** 3

**Difficulty:** easy

## Q5

**Question:** Differentiate between a Menu and a Listbox in Tkinter.

**Answer:** A Menu provides a list of options at the top of the window (used for File, Edit, View style menus). A Listbox shows a list of items and allows selection from the list (used when the user has to pick one or more items from a visible list).

**Difficulty:** medium
