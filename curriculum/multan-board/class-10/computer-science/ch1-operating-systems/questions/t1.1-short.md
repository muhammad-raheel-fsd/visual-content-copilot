## Q1

**Question:** Define Operating System.

**Answer:** Operating System (OS) is a type of system software that manages hardware, runs application software, and provides a user interface like Windows, macOS, Linux, Android, and iOS.

**Marks:** 2

**Difficulty:** easy

---

## Q2

**Question:** How does the OS act as the central system controller?

**Answer:** An operating system works like a traffic controller for the computer. It decides which task should be done first, how the computer's memory is used, and which devices (like a printer or speakers) should be active at a given time. In short, the OS makes sure the computer works smoothly even when multiple tasks are running at the same time.

**Marks:** 3

**Difficulty:** medium

---

## Q3

**Question:** Why is the operating system called a translator?

**Answer:** Computer hardware cannot understand human language directly. The operating system acts as a translator between the user and the hardware system. When a user clicks an icon or types something, the OS changes those actions into instructions the hardware can understand.

**Marks:** 3

**Difficulty:** medium

## Q4

**Question:** List the four responsibilities of the OS in multi-user environments.

**Answer:**
1. The creation and management of separate user accounts.
2. Keeps each user's files and information private.
3. Shares the computer's resources fairly so that no one slows down the systems functionalities.
4. Protects shared resources from unauthorized access.

**Marks:** 4

**Difficulty:** easy

## Q6

**Question:** What is the binary code for the letter A? Explain briefly.

**Answer:** The letter A in binary is 01000001. When a user presses the A key on the keyboard, the operating system converts it into this binary code, which is then sent to the computer screen to display the letter A. The process is so fast that it feels instant to the user.

## Q7

**Question:** Why is each student in a computer lab given a separate account?

**Answer:** In a computer lab, students log in with a username and password provided by the school. Separate accounts keep each student's work separate and private, so one student cannot access another student's files or settings.

**Marks:** 2

**Difficulty:** easy
