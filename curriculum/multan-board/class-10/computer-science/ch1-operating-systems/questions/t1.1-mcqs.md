## Q1

**Question:** What is an Operating System (OS)?

**Options:**
- a) A hardware component that runs inside the CPU
- b) A type of system software that manages hardware, runs application software, and provides a user interface
- c) An application software used for word processing
- d) A network device that connects computers to the Internet

**Correct:** b

**Explanation:** From the book: "Operating System (OS) is a type of system software that manages hardware, runs application software, and provides a user interface like Windows, macOS, Linux, Android, and iOS."

**Difficulty:** easy

**Bloom:** remember

## Q4

**Question:** As the central system controller, the OS decides all of the following EXCEPT:

**Options:**
- a) Which task should be done first
- b) How the computer's memory is used
- c) Which devices should be active at a given time

**Correct:** d

**Explanation:** The book lists three decisions the OS makes as central controller: which task runs first, how memory is used, and which devices are active. Choosing websites is a user action, not an OS decision.

## Q7

**Question:** In a multi-user environment, the OS ensures all of the following EXCEPT:

**Options:**
- a) Creation and management of separate user accounts
- b) Keeping each user's files private
- c) Fair sharing of system resources
- d) Automatic upgrade of computer hardware

**Correct:** d

**Explanation:** The book lists four responsibilities of the OS in multi-user environments: user accounts, privacy, fair resource sharing, and protection from unauthorized access. Hardware upgrades are the responsibility of a technician, not the OS.
