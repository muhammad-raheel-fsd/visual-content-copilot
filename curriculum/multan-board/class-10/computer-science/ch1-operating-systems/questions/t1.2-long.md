## Q1

**Question:** Explain the difference between the kernel and the shell of an operating system. Use the car engine analogy from the book, and include one graphical shell example and one command-line shell example.

**Answer_hint:**
Cover three parts:

1. **Kernel (verbatim):**
   "The kernel is the core part of the operating system, that directly controls the computer's system software and hardware such as the CPU, memory, and devices. It decides how and when different programs can use these resources."
   Book example: "When you open a file, the kernel manages the process of reading it from the hard drive and sending it to the screen."

2. **Shell (verbatim):**
   "The shell is the outer part of the OS that interacts with the user. It receives commands from the user and passes them to the kernel."
   Two types:
   - Graphical shell: Windows desktop, where you click icons and use menus.
   - Command-line shell: Command Prompt or Terminal, where you type instructions.

3. **Car analogy (verbatim):**
   "Like Engine of a car is kernel and accessories like steering wheel, dashboard are shells."
   Explain the mapping: the engine is hidden but does all the real work (kernel controlling hardware), while the steering wheel, pedals, and dashboard are what the driver actually touches (shell talking to the user).

## Q2

**Question:** Describe the layered architecture of an operating system. Explain the role of the lower, middle, and upper layers, and map each layer to the school analogy from the book. State one benefit of the layered design.

**Answer_hint:**
Structure the answer in three parts:

1. **The three layers (verbatim):**
   - "Lower layer work directly with hardware devices like the CPU, RAM, storage and Hard drive."
   - "Middle layer manage these resources and make sure programs can use them when needed."
   - "Upper layer run applications and provide the interface that the user views on the screen."

2. **The school analogy (verbatim):**
   - "The support staff (like guards and cleaners) work at the base, keeping the school ready (like the lower layers working with hardware)."
   - "The administration manages resources, schedules, and rules (like the middle layers managing memory and storage)."
   - "The teachers and students use these arrangements to teach and learn (like the upper layers running applications and interacting with users)."

3. **Benefit of the layered design (verbatim):**
   "Each layer depends on the one below it. This design makes the operating system easier to manage, repair, and improve without changing the whole system."

**Marks:** 10

**Difficulty:** medium

**Expected_answer_length:** 250-350 words
