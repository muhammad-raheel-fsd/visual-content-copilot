## Q1

**Question:** What is a system call?

**Options:**
- a) A phone call between two computers
- b) A request made by a program to the operating system to perform a specific task that the program cannot do directly
- c) A shortcut on the desktop
- d) A type of hardware

**Correct:** b

**Explanation:** From the book: "A system call is a request made by a program to the operating system to perform a specific task that the program cannot do directly."

**Difficulty:** easy

**Bloom:** remember
