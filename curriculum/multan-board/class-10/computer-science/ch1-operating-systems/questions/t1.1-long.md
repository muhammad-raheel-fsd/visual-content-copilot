## Q1

**Question:** Explain the role of the Operating System as the central system controller AND as a translator between the user and the hardware. Include the DO YOU KNOW example of binary encoding.

**Answer_hint:**
The answer must cover two verbatim book sub-topics plus the DO YOU KNOW box:

1. **Central System Controller** (verbatim):
   "An operating system works like a traffic controller for the computer. It decides which task should be done first, how the computer's memory is used, and which devices (like a printer or speakers) should be active at a given time. In short, we can say that the OS makes sure the computer works smoothly even when multiple tasks are running at the same time."

2. **Role in User Hardware Interaction** (verbatim):
   "Computer hardware cannot understand human language directly. The operating system acts as a translator between the user and the hardware system."
   Example: "When you click an icon or type something, the OS changes those actions into instructions that the hardware can understand. This allows people to use computers easily without learning how the hardware works."

3. **DO YOU KNOW binary example** (verbatim):
   "Humans speak languages like Urdu or English, whereas computers understand only binary language, or ON and Off switch i.e. 0 and 1."
   - The letter A in binary is (01000001).
   - This code is sent to the computer screen, which displays A on the screen.
   - The process happens so quickly that it feels instant to the user.

## Q2

**Question:** Describe the responsibilities of an Operating System in a multi-user environment. Give one real-world example for each responsibility.

**Answer_hint:**
The student should list all four responsibilities from the book verbatim, then attach a real-world example to each:

1. **The creation and management of separate user accounts.**
   Example: In a school computer lab, each student has their own username and password provided by the school.

2. **Keeps each user's files and information private.**
   Example: Ali cannot open Ahmed's saved essay from the shared classroom computer.

3. **Shares the computer's resources fairly so that no one slows down the systems functionalities.**
   Example: If ten students run browsers at the same time, the OS gives each one a fair share of memory and CPU time.

4. **Protect shared resources from unauthorized access.**
   Example: A student with a Standard account cannot uninstall a program the teacher has installed, only an Administrative account can.

Also mention the three account types from the book: Standard, Administrative, Guest, with a one-line description of what each can do.

**Difficulty:** medium
