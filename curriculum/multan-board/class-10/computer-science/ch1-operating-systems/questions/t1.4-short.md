## Q1

**Question:** Define Memory in a computer system.

**Answer:** Memory is a fundamental component of a computer system, used to store data and instructions required for processing. It ensures that the CPU can access information quickly during program execution.

**Marks:** 2

**Difficulty:** easy

---

## Q2

**Question:** Define Primary Memory (RAM).

**Answer:** Primary memory, also called Random Access Memory (RAM), is the main working area of a computer. It is a fast storage area where the computer keeps the data and instructions temporarily. Its data is erased when the computer is turned off.

**Marks:** 3

**Difficulty:** easy

---

## Q3

**Question:** Give one example of RAM in use, based on the book.

**Answer:** When you open a Word document, the computer quickly places the program and the document into RAM so the CPU can work on them right away.

**Marks:** 2

**Difficulty:** easy

---

## Q4

**Question:** Define Virtual Memory.

**Answer:** When the RAM is full, the operating system uses part of the computer's storage drive (like Hard drives, solid-state drives (SSD), or Non-Volatile Memory Express (NVMe)) as virtual memory. This extra space acts like temporary RAM, allowing more programs to run at the same time.

**Marks:** 3

**Difficulty:** medium

---

## Q5

**Question:** Why can virtual memory reduce system performance?

**Answer:** Storage drives operate at lower data transfer speeds and have higher access times as compared to RAM; that's why the use of virtual memory can result in reduced system performance.

**Marks:** 3

**Difficulty:** medium

---

## Q6

**Question:** How does the operating system manage memory when several programs are open at the same time?

**Answer:** When several programs are open simultaneously, the operating system may transfer data from less active programs to virtual memory. This frees up space in RAM for the programs you are currently using, but may make those fewer active programs slower to respond.

**Marks:** 3

**Difficulty:** medium
