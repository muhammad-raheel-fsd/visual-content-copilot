## Q1

**Question:** Differentiate between Primary Memory (RAM) and Virtual Memory. Explain when the operating system uses virtual memory and why it can affect performance. Include the Word document example from the book.

**Answer_hint:**
Cover three parts:

1. **Primary Memory (RAM) (verbatim):**
   "Primary memory, also called Random Access Memory (RAM), is the main working area of a computer. It is a fast storage area where the computer keeps the data and instructions temporarily. Its data is erased when the computer is turned off."
   Example: "When you open a Word document, the computer quickly places the program and the document into RAM so the CPU can work on them right away."

2. **Virtual Memory (verbatim):**
   "When the RAM is full, the operating system uses part of the computer's storage drive (like Hard drives, solid-state drives (SSD), or Non-Volatile Memory Express (NVMe)) as virtual memory. This extra space acts like temporary RAM, allowing more programs to run at the same time."

3. **Why performance can reduce (verbatim):**
   "Storage drives operate at lower data transfer speeds and have higher access times as compared to RAM; that's why the use of virtual memory can result in reduced system performance."

Point out the key differences: RAM is fast + temporary + erased on power off; virtual memory borrows from storage + is slower + used only when RAM is full.

## Q2

**Question:** Explain how the operating system manages memory when many programs are open at the same time. State the trade-off it makes and describe how a user might experience it.

**Answer_hint:**
Cover the transfer mechanism (verbatim) and the trade-off:

1. **Transfer mechanism (verbatim):**
   "When several programs are open simultaneously, the operating system may transfer data from less active programs to virtual memory. This frees up space in RAM for the programs you are currently using, but may make those fewer active programs slower to respond."

2. **The trade-off:**
   - Benefit: more programs can be open at once without freezing the whole system.
   - Cost: the programs whose data got moved to virtual memory will feel slower when the user switches back to them.
   - Root cause: storage drives are slower than RAM, so reading data back from virtual memory takes longer than reading from RAM directly.

3. **User experience:**
   Example: if a user has 20 tabs open in a browser and switches to a tab that has not been active for a while, the tab may take a second or two to redraw. That delay is because the browser's data for that tab was moved to virtual memory and now has to be read back from the storage drive into RAM.

**Marks:** 8

**Difficulty:** medium

**Expected_answer_length:** 200-280 words
