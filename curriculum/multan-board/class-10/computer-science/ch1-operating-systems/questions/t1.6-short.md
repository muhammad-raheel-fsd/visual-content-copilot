## Q1

**Question:** Define a system call.

**Answer:** A system call is a request made by a program to the operating system to perform a specific task that the program cannot do directly. They act as a bridge between user programs and the kernel, allowing applications to access hardware and core OS functions safely.

**Marks:** 3

**Difficulty:** easy

---

## Q2

**Question:** Why do we need system calls?

**Answer:** Without system calls, programs that directly control hardware can be unsafe and complex. System calls act as a bridge between user programs and the kernel, allowing applications to access hardware and core OS functions safely.

**Marks:** 3

**Difficulty:** medium

---

## Q3

**Question:** Give one real-world example of a system call, based on the book.

**Answer:** When you save a file in a text editor, the program uses a system call to tell the operating system to write the data to the storage drive (like a Hard drive).

**Marks:** 2

**Difficulty:** easy

---

## Q4

**Question:** List the four main types of system calls with a one-line description of each.

**Answer:**
1. open: Opens a file for reading or writing.
2. read: Retrieves data from a file or input device.
3. write: Sends data to a file or output device.
4. fork: Creates a new process by duplicating an existing one.

**Marks:** 4

**Difficulty:** easy

---

## Q5

**Question:** Give the book's example for the `fork` system call.

**Answer:** Opening a new browser tab, where the OS may use fork to create another process.

**Marks:** 2

**Difficulty:** medium

## Q6

**Question:** Compare the number of system calls in Linux/macOS and Windows.

**Answer:** Linux and macOS have a few hundred system calls, while Windows uses nearly 2,000. These calls handle everything from opening files to running apps and showing graphics in the background while you work.

**Marks:** 2

**Difficulty:** easy
