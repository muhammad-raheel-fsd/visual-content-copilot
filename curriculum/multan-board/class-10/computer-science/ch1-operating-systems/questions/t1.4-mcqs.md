## Q1

**Question:** According to the book, what is the purpose of memory in a computer system?

**Options:**
- a) To generate electricity
- b) To store data and instructions required for processing
- c) To cool down the CPU
- d) To display graphics on the screen

**Correct:** b

**Explanation:** From the book: "Memory is a fundamental component of a computer system, used to store data and instructions required for processing."
