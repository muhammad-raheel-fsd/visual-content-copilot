## Q1

**Question:** What is a file system?

**Answer:** A file system is the way an operating system stores and organizes files on a storage device, such as a hard drive, SSD, or USB. It decides where each file will be kept and save its location so it can be access later. It provides a structured way for users and applications to store, locate, and manage information on storage devices.

**Marks:** 3

**Difficulty:** easy

## Q2

**Question:** Define a file.

**Answer:** A file is a collection of related data stored on a computer. It may contain text, images, audio, video, or program instructions.

**Marks:** 2

**Difficulty:** easy

---

## Q3

**Question:** Define a folder.

**Answer:** A folder (also called a directory) is a container used to organize files and other folders in a logical structure, making it easier to locate and manage information.

**Marks:** 2

**Difficulty:** easy

---

## Q4

**Question:** Define metadata and give three examples of what it includes.

**Answer:** Metadata refers to details about a file, folder, such as its name, type, size, date of creation, and date of last modification. This information helps both the operating system and the user identify and manage files/ folders without opening them.

**Marks:** 3

**Difficulty:** medium

## Q5

**Question:** List four widely used file systems and the OS they belong to.

**Answer:**
1. FAT 32 - Used in USB flash drives.
2. NTFS - Used by Windows OS.
3. APFS / HFS+ - Used by macOS.
4. EXT4 - Commonly used by Linux OS.

**Marks:** 4

**Difficulty:** easy

## Q6

**Question:** What does the choice of file system affect?

**Answer:** The choice of file system affects performance, storage capacity, and security features.

**Question:** Explain the librarian analogy from the book with one line.

**Answer:** If you save a photo on your computer, the file system makes sure it is stored in the right place and knows exactly where to find it when you open it again, just like a librarian placing a book in the right section and knowing where to locate it later.
