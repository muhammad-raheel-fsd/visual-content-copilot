## Q1

**Question:** What is a process?

**Options:**
- a) A physical part of the CPU
- b) An independent program that is currently being executed by the computer
- c) A file on the hard drive
- d) A single instruction

**Correct:** b

**Explanation:** From the book: "A process is an independent program that is currently being executed by the computer."
