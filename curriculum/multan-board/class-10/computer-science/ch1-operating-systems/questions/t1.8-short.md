## Q1

**Question:** Why are there different types of operating systems?

**Answer:** Operating systems are designed according to the needs of the device and the work it performs. Each type serves a different purpose and is optimized for specific tasks.

**Marks:** 2

**Difficulty:** easy

---

## Q2

**Question:** Define a Real-Time Operating System (RTOS) and give one use case.

**Answer:** A Real-Time Operating System is designed to process data and respond within a strict time limit, known as a deadline. It is used where even a tiny delay can cause system failure or serious consequences. It is used in critical systems such as air traffic control, heart-monitoring devices, or industrial robots.

**Marks:** 3

**Difficulty:** medium

---

## Q3

**Question:** Define an Embedded Operating System (EOS).

**Answer:** An Embedded OS is a small and highly efficient operating system built into a specific device to control only the functions it needs. It is not meant for general-purpose computing but is optimized for one task or a small set of tasks. Its key feature is that it uses very little memory and power, and is often stored permanently inside the device.

**Marks:** 3

**Difficulty:** medium

---

## Q4

**Question:** List three devices that use an Embedded OS.

**Answer:** Home appliances (microwaves, washing machines), printers, smart TVs, and ATMs.

**Marks:** 2

**Difficulty:** easy

## Q5

**Question:** Define a Network Operating System (NOS).

**Answer:** A Network OS manages and supports multiple computers connected through a network. It enables the sharing of resources like files, printers, and internet connections among users like windows multipoint servers. Its key feature is that it focuses on communication and coordination between computers.

**Marks:** 3

**Difficulty:** medium

---

## Q6

**Question:** Give the book's example of a Network OS in a school setting.

**Answer:** In a school computer lab, students use different computers, but all can save files to the same server and print from the same printer, thanks to the Network OS.

**Marks:** 2

**Difficulty:** easy

## Q7

**Question:** Define a Mobile Operating System.

**Answer:** A Mobile OS is designed for smartphones, tablets, and other handheld devices. It is optimized for touch-screen use, battery saving, and mobile apps. Its key feature is that it supports wireless connectivity, cameras, sensors, and app stores.

**Marks:** 3

**Difficulty:** easy

## Q8

**Question:** Give one historical fact about mobile operating systems from the book's DO YOU KNOW box.

**Answer:** The very first mobile operating systems, like Symbian (used in early Nokia phones), could only run a few small apps. Today's mobile OS platforms like Android and iOS can handle millions of apps, 3D games, and even professional video editing tools.

**Difficulty:** easy
