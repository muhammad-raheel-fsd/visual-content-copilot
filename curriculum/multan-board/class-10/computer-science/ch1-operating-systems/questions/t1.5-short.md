## Q1

**Question:** Define a process.

**Answer:** A process is an independent program that is currently being executed by the computer. It has its own memory space CPU time, and other resources (such as files or network connections). Processes are isolated from one another to ensure stability and security; a problem in one process generally does not affect another.

**Marks:** 3

**Difficulty:** easy

---

## Q2

**Question:** Define a thread.

**Answer:** A thread is the smallest unit of execution within a process. Multiple threads can exist inside a single process, each performing a different task. All threads in the same process share the same memory and resources, but operate independently.

**Marks:** 3

**Difficulty:** easy

---

## Q3

**Question:** Explain the web browser example given in the book to illustrate processes and threads.

**Answer:** The entire browser application is one process. Within this process, different threads are responsible for one thread loading and rendering a webpage, the second thread playing audio or video content, and another thread downloading files in the background. Using multiple threads, the browser can continue loading new content while playing a video, without making the user wait for one task to finish before starting another.

**Marks:** 4

**Difficulty:** medium

## Q4

**Question:** Define Multithreading.

**Answer:** Multithreading is an operating system technique that allows a single process to perform multiple tasks at the same time by dividing its work into smaller units called threads. Each thread runs independently but shares the same memory and resources of the process, enabling faster execution, better responsiveness, and efficient use of system resources.

**Marks:** 3

**Difficulty:** easy

---

## Q5

**Question:** List the four benefits of multithreading.

**Answer:** Enhanced Performance, Improved Responsiveness, Support for Concurrent (parallel) Operations, and Efficient Use of Resources.

**Marks:** 2

**Difficulty:** easy

---

## Q6

**Question:** Explain how multithreading improves responsiveness, using the book's example.

**Answer:** Applications remain responsive even when one thread is busy with a specific task. Example: A word processor enables continuous typing while another thread checks spelling in the background.

**Marks:** 3

**Difficulty:** medium

---

## Q7

**Question:** Why does multithreading use system resources efficiently?

**Answer:** Threads share the same memory space and resources of their parent process, requiring fewer system resources compared to creating separate processes.

**Marks:** 2

**Difficulty:** medium
