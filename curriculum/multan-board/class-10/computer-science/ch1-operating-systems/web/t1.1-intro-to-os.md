You already use operating systems every day. Windows, macOS, Linux, Android and iOS are all examples. In this topic, we look at what the operating system (OS) does behind the screen. It controls the whole computer. It also keeps users safe when many people share one machine.

:::definition{source="Computer Science and Entrepreneurship 10 (PECTAA), topic 1.1"}
Operating System (OS) is a type of system software that manages hardware, runs application software, and provides a user interface.
:::

## Operating System (OS) as the Central System Controller

Think of a busy road crossing. A traffic controller decides who goes first. The OS does the same job inside your computer. It makes three kinds of decisions:

- Which task runs first.
- How the computer's memory is used.
- Which devices, like a printer or speakers, are active at a given time.

Because of these decisions, the computer keeps working smoothly, even when many tasks run at the same time.

:::example
You play music, open a web browser and print a page, all at once. All three want the computer's attention. The OS decides who gets what, and when, so nothing gets in the way of anything else.
:::

## Role in User Hardware Interaction

Computer hardware does not understand human language. So the OS works as a translator between you and the hardware. When you click an icon or type a key, the OS turns that action into instructions the hardware understands. This is why you can use a computer without knowing how its parts work inside.

:::did-you-know
Computers understand only binary language: 0 and 1, like OFF and ON switches. When you press the letter A, the OS turns it into the binary code 01000001. That code goes to the screen, and you see the letter A. It all happens so fast that it feels instant.
:::

## Responsibilities in Multi-User Environments Tasks

In schools, offices and online systems, many people may use the same computer. Here the OS has four duties. In the book's words, the OS ensures:

- The creation and management of separate **user accounts**.
- Keeps each user's files and information **private**.
- Shares the computer's resources fairly so that no one slows down the systems functionalities.
- Protect shared resources from **unauthorized access**.

Resources are the things every program needs, such as memory, processor time and devices. "Unauthorized access" means someone using something they have no permission to use.

## Creating and Managing User Accounts

The OS lets every user have a separate account. Each account has its own desktop, files, settings and password. You log in with your username and password, and you see only your own work.

:::example
In a school computer lab, each student logs in with a username and password given by the school. Ali's homework stays inside Ali's account. Ahmed logs in on the same computer, but he cannot see it.
:::

In modern operating systems like Windows, you can add a new account in a few steps:

1. Open **Settings** or **Control Panel**.
2. Select **User Accounts**.
3. Choose **Add New User**.
4. Enter the details: username, password and account type.

Windows offers three account types: **Standard**, **Administrative** and **Guest**. They differ in what a user is allowed to install, change or access.

:::did-you-know
Operating systems are not only on laptops and phones. NASA's Mars rovers Curiosity and Perseverance also run an operating system, called VxWorks.
:::
