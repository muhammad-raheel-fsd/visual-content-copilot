# Brand name candidates (checked 2026-10-09)

The brand for the whole studio: website, YouTube, Instagram, TikTok, WhatsApp channel and
everything else. Today the site runs as "CS Classroom", but `csclassroom.com` and
`@csclassroom` on YouTube are both taken, so a new name is needed and I prefer nuktadaan, Actism, Claropedia.

**What the name must say:** we teach logic, concepts and ideas, not rote theory, so students
really understand and improve.

**Rules Muhammad set:**

- Premium and memorable, like Notion or Duolingo; easy on the tongue; real words with real
  meaning (no invented sounds like "Ilmzio" or "Samivio").
- Urdu, Persian or Arabic roots are welcome (qalam, sabaq, nukta, fikr, mantiq...), English too.
- **Zero conflicts:** `.com`, `.pk`, YouTube, Instagram, TikTok and every other platform must be
  free, and no other brand may use the name.

**Availability changes daily.** Everything below was true on 2026-10-09. Re-check before buying
and register the domains and all handles on the same day.

## 0. Scorecard of every name in this file (Claude's honest scores, 2026-10-09)

All 144 names in this file, scored the same way so they can be compared fairly.

**How the score is made:** five qualities, each out of 10, then one weighted score:

| Quality      | Weight | Question                                                         |
| ------------ | ------ | ---------------------------------------------------------------- |
| Meaning      | 30%    | does it say "logic and concepts, not rote"?                      |
| Premium      | 30%    | serious and trustworthy, not childish or jokey?                  |
| Memorable    | 15%    | does it stick after hearing it once?                             |
| Easy         | 15%    | can a student say and spell it after hearing it once?            |
| Grows        | 10%    | does it still fit beyond CS (AI, maths, other subjects)?         |

**Score = 0.30 meaning + 0.30 premium + 0.15 memorable + 0.15 easy + 0.10 grows.**

Availability is not mixed into the score: a taken name cannot be used however good it is, so the
names are split into A (free everywhere: the real choices), B (partly free) and C (not available:
the score it would have). The scores are opinions; the availability is checked fact (section 4).

**Conceptistan in detail (Muhammad's favourite):** 7.8 / 10 (number 7 of 50 in table A).

  subjects as regions, the Daily 5 as a daily "border check"); free everywhere; not limited to CS.
- **Against:** playful rather than premium (closer to Duolingo than Notion), so the logo and voice
  must be clean and grown-up; some people outside Pakistan know jokey "-istan" words
  ("Absurdistan"); 12 letters and easy to misspell as "Conceptstan".
- **Typo domains (free on 2026-10-09):** `conceptstan.com`, `conceptisthan.com`,
  `konceptistan.com`. Register `conceptstan.com` as a redirect.
- **Could reach 9** with a premium visual identity and a calm, confident voice (its premium
  score of 6 is the only thing holding it back).
- **Taglines:** "Conceptistan: where concepts live." / "Ratta nahi, concept." /
  "Welcome to Conceptistan." (video opener)

**Why Logicistry scores highest (8.7):** one word, instantly understood ("the science of logic"),
sounds like a school subject (chemistry, geometry), so it feels serious and trustworthy to
students, parents and professionals alike; works on LinkedIn as well as on YouTube; free on
every platform checked. Weak points: 10 letters, and "-istry" must be spelled right.
Typo domains free on 2026-10-09: `logicestry.com`, `logicstry.com`, `logiccistry.com`
(register `logicstry.com` as a redirect). "Logistry" is taken.

**What makes any of these a 10:** a name gets to 10 through use, not on paper: one clean logo,
one consistent voice, the same handle everywhere, and content that keeps the promise.

## 4. How each check was done (so it can be repeated)

| Check              | Method                                                                                                         | "Free" means                       |
| ------------------ | -------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| `.com`, `.net`     | RDAP at Verisign: `https://rdap.verisign.com/com/v1/domain/NAME.com`                                           | HTTP 404 (not registered)          |
| `.pk`              | PKNIC lookup: `https://pk6.pknic.net.pk/pk5/lookup.PK?name=NAME.pk`                                            | page says "available for registration" |
| `.dev`, `.app`     | Google Registry RDAP: `https://pubapi.registry.google/rdap/domain/NAME.dev`                                    | HTTP 404                           |
| `.io`, `.academy`  | Identity Digital RDAP: `https://rdap.identitydigital.services/rdap/domain/NAME.io`                             | HTTP 404                           |
| `.org`             | PIR RDAP: `https://rdap.publicinterestregistry.org/rdap/domain/NAME.org`                                       | HTTP 404                           |
| YouTube            | `https://www.youtube.com/@NAME`                                                                                | HTTP 404                           |
| TikTok             | `https://www.tiktok.com/@NAME` (page JSON)                                                                     | `"statusCode":10221` (no such user) |
| GitHub             | `https://github.com/NAME`                                                                                      | HTTP 404                           |
| Web                | web search for the exact name (brands, apps, companies, social profiles)                                       | no matching brand                  |

Controls used to prove the checks work: `fireship` (exists: taken everywhere) and a nonsense
name (free everywhere).
